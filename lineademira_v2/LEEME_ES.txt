LINEA DE MIRA ANDROID 2.0 — FUENTES Y COMPILACION

ESTADO
Este archivo contiene el codigo fuente actualizado y el flujo de compilacion ARMv7 para GTA SA Android 2.00 + AML. Todavia no incluye libLineaDeMira.so 2.0, por lo que no se instala copiando el contenido directamente al telefono.

CAMBIOS DEL CODIGO
- Conserva el ajuste de camara en primera persona y los perfiles por arma existentes.
- Añade un hook opcional de CHud::DrawCrossHairs. Si el simbolo existe y AML acepta el hook, el plugin oculta la reticula original con armas compatibles mientras se camina.
- Reticula_Centro.csa dibuja una cruz central propia.
- El juego conserva el calculo original de disparo e impactos; esta version no intercepta ni reemplaza esa rutina.
- Si falta el simbolo o AML no registra el hook, la rutina original no se suprime.

CONTENIDO
- src/mira.cpp, src/mira.h: plugin AML nativo, dirigido a ARMv7 (32 bits).
- CLEO/*.csa: script de primera persona y reticula central.
- configs/LineaDeMira.ini: correcciones iniciales por arma.
- .github/workflows/lineademira.yml: compilacion NDK, comprobacion de arquitectura y empaquetado del ZIP instalable.

PARA OBTENER EL ZIP INSTALABLE
El flujo de compilacion debe ejecutarse en un repositorio GitHub con Android NDK. El repositorio conectado disponible es publico; la revision automatica no permitio publicar alli estos fuentes sin permiso explicito. Si autorizas expresamente subir este contenido a la rama lineademira-custom-aim-v2, puedo iniciar la compilacion y entregarte el ZIP ARMv7 resultante. Otra opcion es colocar esta carpeta en tu propio repositorio privado con GitHub Actions.

COMPATIBILIDAD
No instalar este codigo fuente como si fuera un mod. El plugin solo se dirige a armv7/32 bits y a la version del juego cuya direccion/layout valida la fuente. No es un build arm64. La prueba visual final de la reticula requiere ejecutarlo en el telefono.
